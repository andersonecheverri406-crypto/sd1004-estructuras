# sd1004-estructuras
Reto de Estructuras de Datos

Dibujé diferentes estructuras de datos, como listas, pilas, colas, árboles y grafos, mostrando de manera sencilla cómo se organizan los datos.

La estructura que más me costó fue el árbol, porque tiene una organización jerárquica y es necesario entender cómo se relacionan los nodos.

Aplicaciones
WhatsApp: Puede utilizar colas para organizar y procesar los mensajes en el orden en que llegan.
Instagram: Puede utilizar grafos para representar las conexiones entre usuarios, seguidores y cuentas.
Spotify: Puede utilizar listas para organizar las canciones dentro de las listas de reproducción.

Este ejercicio me ayudó a relacionar las estructuras de datos con aplicaciones que utilizamos diariamente.
